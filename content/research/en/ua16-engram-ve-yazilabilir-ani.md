# UA-16 — Engram and Writable Memory: Whose Property Is Memory?

This dossier examines how memory is stored in the brain and, crucially, how it is **rewritten**. It places side by side the optogenetic experiments that produce, implant and re-valence memories in mice with the human research on the post-retrieval write window (reconsolidation). It closes with a candidate law that defines memory as "file + access key" and proposes that identity is not the stored content but the **access pattern**.

## 1. Intersection Map: Molecular Biology, the Clinic and Philosophy Ask the Same Question

Three lines intersect here:

1. **Molecular neuroscience** — where is the memory trace (engram), across how many cells, written by which molecules?
2. **Optogenetics** — can a memory be switched on, off, or even written in the laboratory?
3. **Clinical psychology/pharmacology** — can a traumatic memory's emotional load be reduced without erasing it?

Why do they not merge? Because merging them yields this sentence: **a memory is not a fixed record; it is a rewritable file reconstructed at every recall.** This sentence shakes both the "memory = archive" view and the assumption that "changing memories is an unethical intervention" — the intervention is already happening at every recall.

## 2. Anomaly Inventory (with citations)

### 2.1 Birth of a concept and an unfinished search

Semon (1904) named the memory trace the "engram"; Lashley (1950, *Symposia of the Society for Experimental Biology* 4:454–482), after decades of lesion experiments, published his famous conclusion: memory seemed to be held not in one place but distributed. "Where is the engram?" stayed technically unanswerable for half a century.

### 2.2 Optogenetics: the memory's on switch

Liu et al. (2012, *Nature* 484:381–385) labeled hippocampal cells active during fear learning (engram cells), then **optogenetically stimulated only those cells**: the mouse showed the fear response without any cue. The memory was, by definition, recalled — content becomes accessible through activation of the right cell set.

Ramirez et al. (2013, *Science* 341:387–391) co-activated engram sets from two different contexts and produced the recall of a **never-experienced memory**: the mouse displayed, in room B, a fear it had associated with room A. Redondo et al. (2014, *Nature* 513:426–430), stimulating the same engram, **flipped a memory's emotional valence**: a fear-tagged memory shifted toward reward.

Josselyn and Tonegawa (2020, *Science* 367:eaaw4325) conclude in their review that the engram is a physically definable cell set — but that its **activation** and its **content** are separate things.

### 2.3 Silent engrams: stored but inaccessible memories

Work such as Roy et al. (2017) showed that some memories remain "silent": content is stored, but the access route is closed. This splits the sentence "I forgot" in two: a **storage failure** or an **access failure**?

### 2.4 Sleep: the nightly replay

Wilson and McNaughton (1994, *Science* 265:676–679) showed that hippocampal cell sequences in sleeping rats **replayed the path taken during the day in the same order**. Memory is recorded by day, consolidated by night, and access keys are reorganized in the process. This links directly to the multi-scale rhythm locking of HP-1 and the nightly calibration of UA-08.

### 2.5 The post-retrieval write window (reconsolidation)

Nader, Schafe and LeDoux (2000, *Nature* 406:722–726) showed that if protein synthesis is blocked after a fear memory is recalled, the memory **cannot be re-written** (and weakens). At the moment of recall the memory temporarily becomes "writable": the *reconsolidation window*.

In humans: Kindt, Soeter and Vervliet (2009, *Nature Neuroscience* 12:256–258) reported that the beta-blocker propranolol given after recall prevented the fear response from returning; Soeter and Kindt (2015, *Biological Psychiatry* 78:880–886) observed an abrupt transformation in phobic behavior.

**The honest counter-argument:** Elsey, Van Ast and Kindt (2018, *Psychological Bulletin* 144:797–848) show the human reconsolidation evidence to be consistent yet complex, most studies small, and the protocols hypersensitive to detail. The door to "rewriting memory" is real, but its opening is narrow.

### 2.6 Context-dependent recall: proof of the access key

Godden and Baddeley (1975, *British Journal of Psychology* 66:325–331) showed that words learned underwater versus on land were recalled better **in the environment where they were learned**. This classic context-dependency finding confirms the "access key" component of the engram model in humans: content constant, access conditional.

## 3. Three-Level Excavation

### Level 1 — Observation
- A memory can be traced to a definable cell set (the engram).
- Stimulating that set recalls the memory; co-activating sets produces a false memory.
- Emotional valence can be changed independently of content.
- Some memories are stored but inaccessible ("silent engram").
- Memory sequences replay during sleep.
- Recall opens a brief write window.
- Recall depends on the conditions of learning.

### Level 2 — Pattern
A two-layer pattern: **(A) File and key are separate.** The content of a memory (the engram) and the condition of access to it (activation, context, state) are different physical systems. **(B) The key temporarily makes the file writable.** Recall is not read-only; it briefly opens write permission. The classical archive metaphor is therefore wrong: memory is not a read-only disk but a database that performs **small write operations at every access**.

### Level 3 — Why is it designed this way?
Because an absolute record would hold the organism hostage to its past. The environment changes; last year's correct path may be dangerous now. The system must store content but be able to **update the tag and the access route**. Write permission is therefore tied to two gates: (i) the natural window at recall, and (ii) context/state matching. Memory thus preserves identity continuity while staying current through the principle that "every read is a small rewrite".

The critical consequence: **identity is not the sum of stored contents but which key opens which file.** Two people can hold the same memories; if the access pattern differs, they are two different people.

## 4. HIDDEN PATTERN CANDIDATE: HZ-16 — Engram + Access Key

> **Candidate Law (HZ-16).** Memory splits into two physical components: a distributed content trace (engram) and the condition that activates it (access key). Measured "recall" is their match; when the match fails, content exists but recall does not. Recall temporarily converts the access key into **write permission** (the reconsolidation window).

Simplified expression:

**Recall = Engram_content × Key_match(Encoding_state, Retrieval_state)** &nbsp;&nbsp; and if Key_match → 0 then recall → 0.

**Sub-law (HZ-16a — the write window).** For minutes to hours after recall, a memory's emotional tag and contextual labels can be rewritten while content is largely preserved. That is: **the tag is writable, the content semi-protected.**

**Discriminating test (HZ-16/1 — state matching).** Participants encode word lists in two different autonomic states (slow breathing, parasympathetic; fast tempo, sympathetic) and are tested in both. Prediction: recall rises significantly with **state matching**, and the gain correlates with the measured HRV/vagal difference (linking to UA-25).

**Second test (HZ-16/2 — tag or content?).** In a post-recall beta-blocker group: (i) implicit measures (skin conductance) should drop, (ii) explicit content recall should be preserved, (iii) reinstatement of fear one month later should not occur. Prediction: if content and tag dissociate, HZ-16a is supported; if they do not dissociate, the law weakens.

**Third test (HZ-16/3 — the human analogue of silent engrams).** In participants reporting "I forgot", measure how much content is recovered through state matching (same odour/sound/autonomic state) and cue enrichment. Prediction: a portion of "lost" memories will be recovered because the failure was access, not storage.

## 5. Evidence Thermometer: 🟢 (mechanism demonstrated in animal models; human write-window evidence strong but contested)

**Why 🟢?** The existence and excitability of engram cells, the creation of false memories and the re-valence of memories were demonstrated in independent laboratories; replay during sleep has been measured; context dependency and reconsolidation effects have been replicated in humans.

**Why not a perfect score?** (1) Optogenetics cannot be applied to humans; engram work rests on animal models. (2) The human reconsolidation literature is heterogeneous (Elsey et al. 2018). (3) "Silent engrams" can only be inferred behaviourally in humans.

> **If refuted, what survives?** If the reconsolidation model collapses, the separation "memory = distributed trace + access key" still stands — it is independently supported by context dependency, state dependency and cueing effects. The dossier keeps its main claim even if its weakest link breaks.

## 6. Practical Implications and the Gateway Bridge

1. **The session state is part of the record.** The same information is encoded at different depths in different autonomic states; stable, ritualized sessions (same light, sound, breathing pace) therefore strengthen learning — this is a measurable memory effect, not a mystical claim.
2. **Recalling is updating.** Every time we tell a memory we rewrite it slightly; this is the physiological ground on which traumatic memories can change in narrative therapy. But the window is narrow: not casual conversation, but **controlled recall plus a safe context**.
3. **Forgetting is not always loss.** "Silent" memories open with the right key; cue enrichment and multi-modal reminders are therefore the most solid memory aids in aging.
4. **Caution.** Reconsolidation protocols in trauma (propranolol, EMDR) remain investigational; self-administered intervention is not advised and clinical supervision is required.
5. **Research note:** this file belongs to the same "access/key" family as UA-05 (filter curve), UA-08 (sleep), UA-25 (autonomic state) and UA-36 (interoception); the shared sentence: **content is fixed, access is state-dependent.**
